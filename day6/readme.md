## Observations

### 1. More Training Data Improved the Model’s Accuracy
At the beginning, when I trained the model with only a few samples, the predictions were inconsistent and sometimes incorrect. After increasing the number of training images, the model became much more stable and confident in its predictions. This showed me that machine learning models learn better when they are exposed to more examples and variations of the same object.

### 2. Different Backgrounds and Lighting Conditions Helped Generalization
Initially, the model performed well only in the same environment where the training data was collected. However, after adding images with different lighting conditions, camera angles, and backgrounds, the model started recognizing the objects more reliably in new situations as well. This helped me understand that diverse training data is important because real-world inputs are never perfectly identical.

### 3. Noisy or Incorrect Data Reduced Prediction Quality
When I intentionally added blurry images, incorrect labels, and inconsistent samples, the model’s performance dropped noticeably. The predictions became less confident and sometimes completely wrong. This experiment demonstrated how sensitive machine learning models are to data quality. It made me realize that even a powerful model can fail if the training data is poor or misleading.

## Key Learning

This activity helped me build an intuitive understanding of machine learning. I learned that a model does not “understand” objects like humans do — it only learns patterns from the examples it is given. The quality, quantity, and consistency of data directly affect how well a model performs.
