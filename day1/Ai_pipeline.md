# Ai pipeline: 
As the term suggest Ai pipeline is the sequence of steps used to build deploy and maintain Ai.
-> Simple stages in Ai pipeline:
    Input -> Processing -> Output
-> Core stages in Ai pipeline(big picture)

a. Data ingestion & collection
b. Data preprocessing & Cleaning
c. Feature Engineering
d. Model training
e. Model evaluation and Tuning
f. Monitoring and feedback


# Ai Chatbot Pipeline:
 User message -> Text Processing -> Language Model Processing -> Response -> Final Answer
